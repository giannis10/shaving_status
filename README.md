# Smooth Status 🪒

Το **Smooth Status** είναι μια υπερσύγχρονη και έξυπνη εφαρμογή καταγραφής της προσωπικής περιποίησης, φτιαγμένη με Flutter. Σε βοηθάει να παρακολουθείς τη ρουτίνα ξυρίσματος/τριμαρίσματος, να διαχειρίζεσαι τα εργαλεία σου και να λαμβάνεις έξυπνες ειδοποιήσεις για να είσαι πάντα στην εντέλεια.

## 🌟 Λειτουργίες

*   **Διαδραστικός Χάρτης Σώματος:** Παρακολούθησε οπτικά την κατάσταση της τρίχας σε διαφορετικά σημεία του σώματος (Πρόσωπο, Στήθος, Πόδια κλπ.) μέσα από έναν εύχρηστο 3D-like χάρτη (Μπρος/Πίσω).
*   **Έξυπνες Ειδοποιήσεις (Brain Mode 🧠):** Ξέχασε τα χειροκίνητα ξυπνητήρια. Το Smooth Status αναλύει το ιστορικό σου για να υπολογίσει την προσωπική σου ώρα περιποίησης και προγραμματίζει αυτόματα την επόμενη ειδοποίηση την ώρα που *εσύ* συνήθως ξυρίζεσαι!
*   **Διαχείριση Εργαλείων:** Κατέγραψε τα ξυραφάκια, τις μηχανές και τις λεπίδες σου. Δες πόσες φορές έχεις χρησιμοποιήσει την κάθε λεπίδα και πότε ήρθε η ώρα για αλλαγή.
*   **Αναλυτικά Στατιστικά:** Δες το ιστορικό σου, παρακολούθησε τη συνέπειά σου και βγάλε χρήσιμα συμπεράσματα για τις συνήθειές σου ανά μήνα ή έτος.
*   **Premium Dark UI:** Ένα πανέμορφο, ζωντανό σκοτεινό θέμα (Dark Mode) με εφέ glassmorphism, ρευστές κινήσεις και μοντέρνο κάτω μενού (Floating Nav Bar).
*   **Απόλυτη Ιδιωτικότητα (Offline First):** Κανένα προσωπικό δεδομένο δεν αποστέλλεται στο διαδίκτυο ή σε κάποια εξωτερική βάση δεδομένων (DB). Όλο το ιστορικό και οι συνήθειές σου αποθηκεύονται αποκλειστικά 100% τοπικά στη συσκευή σου.
*   **Πολυγλωσσικό:** Πλήρης υποστήριξη για Ελληνικά και Αγγλικά, με εύκολη εναλλαγή από τις ρυθμίσεις.

## 🚀 Ξεκινώντας

### Απαιτήσεις
*   Flutter SDK (3.x)
*   Android Studio / Xcode για εξομοιωτές και build

### Εγκατάσταση
1. Κατέβασε τον κώδικα ή κάνε clone το repository.
2. Άνοιξε το τερματικό μέσα στον φάκελο `shaving_status`.
3. Τρέξε `flutter pub get` για να κατέβουν όλα τα απαραίτητα πακέτα.
4. Τρέξε `flutter run` για να ξεκινήσει το app στο κινητό σου ή στον εξομοιωτή.

## ⚙️ Πώς λειτουργεί το "Brain Mode"

Όταν το ενεργοποιείς από τις Ρυθμίσεις, το app χρησιμοποιεί ειδοποιήσεις παρασκηνίου (`flutter_local_notifications`). Υπολογίζει τον **μέσο όρο της ώρας** όλων των καταγεγραμμένων ξυρισμάτων σου. Αν για παράδειγμα ξυρίζεσαι σταθερά γύρω στις 18:30 το απόγευμα, η επόμενη ειδοποίηση θα προσαρμοστεί έξυπνα για να χτυπήσει εκείνη ακριβώς την ώρα!
